# RailRoute Optimizer

Frontend-only приложение для оптимизации месячного календарного графика железнодорожной погрузки.

## Возможности MVP
- импорт Excel: `Календарный график`, `Фронты`, `Грузы по фронтам`, `Нормы маршрутов`;
- критическая валидация входных данных;
- фиксация уже готовых маршрутов;
- перераспределение остатка в настраиваемом окне назад/вперёд;
- учёт специализации и вместимости фронтов;
- расчёт в Web Worker через Comlink;
- Redux Toolkit как единый runtime-state;
- экспорт результата в Excel;
- приложение не отправляет производственные данные на сервер.

## Важно
Текущий MVP содержит детерминированный оптимизационный engine для проверки полного пользовательского workflow. Следующий production milestone — замена candidate selection в `src/optimizer/engine.ts` на MILP/HiGHS WASM с лексикографическими стадиями из утверждённого ТЗ. Domain API и Worker boundary для этого уже выделены.

